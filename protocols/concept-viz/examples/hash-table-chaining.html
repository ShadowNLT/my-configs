Hash table chaining

A table is an array of slots. A hash maps a key to one slot index.

Two keys can land on the same slot. That event is a collision.

The slot keeps a list. Both keys stay, in arrival order.

Lookup hashes again, then walks that list until the key matches.

Same structure. Answer the question below from the figure.

Key dog hashed to slot 2. Slot 2 already holds cat. How do you still find dog?

Walk the list on slot 2. Skip cat, then match dog. The hash only picks the slot. The list keeps every key that landed there.

Assumes: arrays, a hash that maps a key to a slot index · Teaching: a collision keeps both keys in a list on that slot · Exit: able to find a key after it collided
